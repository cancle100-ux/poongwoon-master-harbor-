# 상승 2파 스크리너 (Wave-2 Setup Screener)

바닥 반전주·이미 급등한 추격주가 아니라, **이미 상승 추세가 검증된 종목 중에서
건전한 조정을 마치고 2파 상승을 준비하는 종목**만 걸러내는 스크리너입니다.
**시장 국면 게이트**로 지수가 무너진 구간의 신호를 거르고, **백테스트**로 기준 자체를 과거 데이터에서 검증합니다.

리포트 페이지: [`wave2.html`](../wave2.html) — 스크리너 실행 결과가 그대로 반영됩니다.

## 선별 기준 6가지 (일봉)

| # | 기준 | 판정 |
|---|------|------|
| 1 | 정배열 | 20일선 > 60일선 > 120일선, 20일선이 20일 전보다 상승 |
| 2 | 건전한 조정 | 최근 20일 고점 대비 **-5% ~ -15%** |
| 3 | 거래량 감소 | 조정 구간(최근 5일) 평균 거래량 ≤ 직전 20일 평균의 **80%** |
| 4 | 20일선 지지 | 종가가 20일선 -1.5% ~ +6% 구간에서 지지·회복 |
| 5 | 과열 해소 | RSI(14) **45 ~ 60** |
| 6 | 반등 트리거 | 당일 양봉 또는 단기(5일) 고점 돌파 직전(-1.5% 이내) |

## 시장 국면 게이트

개별 종목이 아무리 좋은 눌림이어도 지수가 하락 국면이면 눌림목 매매의 승률이 한꺼번에 떨어집니다.
그래서 **종목이 속한 지수**(KOSPI 종목은 KOSPI, KOSDAQ 종목은 KOSDAQ)의 국면을 먼저 봅니다.

| 국면 | 조건 (지수 일봉) | 효과 |
|------|------------------|------|
| 우호 | 종가 > 20일선 > 60일선 | 판정 그대로 |
| 주의 | 우호·위험이 아닌 모든 경우 (20일선 아래 단기 조정, 20일선 < 60일선 반등 시도 등) | 판정 유지, "비중 축소" 표기 |
| 위험 | 종가 < 60일선 **그리고** 20일선 < 60일선 | 준비·시동 후보를 **대기로 강등** (대응 가격은 그대로 표시) |

`--no-regime`을 주면 게이트를 끄고 국면은 표시만 합니다.

## 출력 부류 (3+1)

- **조정 완료·재상승 준비** (`ready`) — 기준 1~6 모두 충족. 눌림 매수 관심.
- **재상승 당일 확인** (`ignited`) — 정배열 + 고점 대비 -5% 이내 회복 + 당일 거래량 ≥ 20일 평균
  + 고가권 마감 + RSI ≤ 65. 이미 시동이 걸린 형태.
- **아직 조정 중·대기** (`wait`) — 정배열은 유지되나 일부 기준 미충족, 또는 시장 국면 위험으로 강등.
  미충족 사유가 함께 출력되며, 조건 충족 시 후보로 복귀.
- **별도 분리** (`excluded`) — 정배열 미충족(바닥 반전형), 신고가 돌파 추격형, RSI 65 초과 과열,
  고점 대비 -20% 초과(추세 훼손). 이번 전략의 선별 대상이 아니므로 따로 관리.

각 후보에는 **대응 가격**이 자동 산출됩니다:
핵심 목표(전고점) / 1차 저항(조정 폭 50% 되돌림) / 재상승 확인(단기 고점 돌파) /
관심 구간(20일선 지지권, 항상 현재가 이하) / 추세 경고(조정 저점) /
무효화(얕은 조정은 20일선, 깊은 조정은 60일선).

## 데이터 소스

| 용도 | 출처 | 로그인 |
|------|------|--------|
| 종목 일봉(수정주가), KOSPI·KOSDAQ 지수 | 네이버 금융 차트 | 불필요 (표준 라이브러리로 직접 조회) |
| 유동성(거래대금) 순위 | [pykrx](https://github.com/sharebook-kr/pykrx) → KRX 정보데이터시스템 | **필요** |

현재 pykrx(1.2.9에서 확인)는 KRX 데이터 조회에 로그인이 필요합니다.
[data.krx.co.kr](https://data.krx.co.kr)에 가입한 뒤 환경변수 `KRX_ID`, `KRX_PW`를 설정하세요.
로그인 없이 쓰려면 `--tickers`로 종목을 직접 지정하면 됩니다 (KOSDAQ 종목은 `.KQ`를 붙여 지수를 구분).

## 사용법

### 스크린 (오늘의 후보)

```bash
pip install pykrx
export KRX_ID=아이디 KRX_PW=비밀번호

# 유동성 상위 120종목 스캔 → 시장 국면 게이트 적용 → 리포트 페이지 갱신
python3 screener/wave2_screener.py --live --update-html wave2.html

# 로그인 없이 지정 종목만 (KOSDAQ은 .KQ)
python3 screener/wave2_screener.py --live --tickers 105560,055550,214450.KQ

# 특정 기준일로 스캔하고 JSON 저장
python3 screener/wave2_screener.py --live --date 20260807 --json result.json
```

오프라인 CSV도 됩니다 (일봉 140개 이상 필요). 파일명을 `105560_KB금융.csv`처럼 지으면 코드·이름을 자동 인식합니다.

```bash
# CSV 헤더: 날짜,시가,고가,저가,종가,거래량 (영문 date,open,high,low,close,volume 도 허용)
python3 screener/wave2_screener.py --csv 105560_KB금융.csv 055550_신한지주.csv \
    --index-csv kospi.csv --index-name KOSPI
```

`--update-html`은 `wave2.html` 안의 `/*WAVE2_DATA_START*/ ... /*WAVE2_DATA_END*/`
블록만 교체하므로 페이지 디자인은 그대로 유지됩니다.

### 백테스트 (기준 검증)

```bash
# 최근 3년, 시작일 기준 유동성 상위 120종목, 민감도 분석 포함
python3 screener/wave2_screener.py --live --backtest --years 3 --sweep --json backtest.json

# 진입 방식 비교: 다음날 시가(open) vs 관심 구간 지정가(zone) vs 단기 고점 돌파(breakout)
python3 screener/wave2_screener.py --live --backtest --entry zone
python3 screener/wave2_screener.py --live --backtest --entry breakout

# 지정 종목·CSV로도 가능
python3 screener/wave2_screener.py --live --tickers 105560,055550 --backtest --start 20230101
python3 screener/wave2_screener.py --csv data/*.csv --index-csv kospi.csv --backtest
```

**방법**

- **미래 데이터 미사용**: 과거 구간을 하루씩 전진하며, 매일 *그날까지의* 일봉(최근 250개)만으로
  스크린과 똑같은 판정을 내립니다. 지수 국면도 그날까지의 지수로만 판정합니다.
- **진입** (`--entry`): `open` 신호 다음날 시가 · `zone` 관심 구간 상단 지정가 · `breakout` 단기 고점 한 호가 위 돌파.
  zone·breakout은 최대 5거래일 대기하고, 그사이 종가가 손절선 아래로 가면 취소합니다.
- **청산**: 장중 전고점(목표) 도달 → 목표가 체결 / 종가가 추세 경고선(조정 저점) 아래 → 종가 손절 /
  `--hold`(기본 20) 거래일 경과 → 종가. 종목당 한 번에 한 포지션만 보유합니다.
- **비용**: 왕복 0.3% 가정 (`--cost`로 조정, 세금·수수료·슬리피지 포함 가정치).
- **유니버스**: `--live`는 *시작일* 기준 유동성 상위로 선정해 "지금 잘 나가는 종목만 고르는" 생존 편향을 줄입니다.

**출력 읽는 법**

| 섹션 | 확인할 것 |
|------|-----------|
| 거래 성과 — 게이트 미적용 vs 적용 | 게이트 적용 행의 평균 수익률·PF가 더 좋아야 시장 국면 필터가 값을 합니다 |
| 시장 국면별 | 위험 국면 신호의 성과가 뚜렷이 나쁘면 게이트가 정당화됩니다 |
| 신호 후 수익률 vs 정배열 기준선 | 초과 수익이 양수여야 기준이 "그냥 정배열 종목을 사는 것"보다 낫습니다 |
| 민감도 (`--sweep`) | 현재 기준(*) 주변 셀이 비슷하면 견고한 기준, 한 셀만 튀면 과최적화 의심 (거래 30건 미만 셀은 참고만) |
| 진입 방식 비교 | 확인을 기다릴수록(breakout) 승률은 오르고 손익비는 나빠지는 트레이드오프를 숫자로 확인 |

> 한계: 일봉만으로 체결을 가정합니다 (같은 날 목표가·손절선이 모두 닿으면 장중 목표가 우선,
> 관심 구간 진입일의 목표가 도달은 불인정). 상장폐지로 시세가 사라진 종목은 빠질 수 있습니다.

## 테스트

```bash
python3 -m unittest discover -s screener -v
```

합성 일봉으로 분류·시장 국면·게이트, 진입·청산 규칙, 미래 데이터 미사용(과거 지표가 미래 데이터에 영향받지 않음),
민감도 격자, 네이버 응답 파싱, `--live` 경로 전체(가짜 응답)를 검증합니다. 네트워크 없이 실행됩니다.

## 기준 조정

민감도를 바꾸려면 `wave2_screener.py` 상단의 `CFG` 상수를, 백테스트 기본값은 `BT` 상수를 수정하세요.
(예: 조정 깊이 범위 `pullback_min/max`, 거래량 감소 기준 `vol_contract_max`,
RSI 범위 `rsi_min/max`, 과열 컷 `overheat_rsi`, 민감도 격자 `SWEEP_PULLBACK`·`SWEEP_RSI`)

> ※ 본 도구의 출력은 투자 판단 참고용이며 특정 종목의 매수·매도 권유가 아닙니다.
