# 여수제일병원 홈페이지

의료법인 한마음의료재단 **여수제일병원**의 공식 홈페이지입니다.
목업 디자인을 기준으로 디자인 시스템을 적용해 제작한 반응형 단일 페이지입니다.

## 특징

- **디자인 시스템 기반** — CSS 변수(컬러·간격·그림자·라운드)로 통일된 톤앤매너
- **인터랙티브 효과** — 헤드라인 단어별 등장, 스크롤 페이드업, 숫자 카운트업, MRI 비주얼 애니메이션
- **세련된 의료 톤** — 딥 네이비 + 틸 포인트 컬러, 글래스모피즘 헤더
- **완전한 반응형** — 데스크톱·태블릿·모바일(햄버거 메뉴) 대응
- **외부 의존 없음** — 단일 `index.html`, 이미지 대신 SVG/그래디언트 사용으로 오프라인에서도 정상 렌더링
