# 조기축구 매니저 (poongwoon-master-harbor-)

하버·풍운FC 조기축구 운영을 위한 웹앱 모음입니다. 별도 설치/서버 없이 브라우저에서 바로 열어 쓸 수 있고, 모든 데이터는 기기의 `localStorage`에 저장됩니다.

## 📁 구성

| 파일 | 설명 |
|------|------|
| [`manage.html`](manage.html) | **조기축구 관리앱** — 선수단·출석·전술/포지션·회비를 한 곳에서 관리 |
| [`index.html`](index.html) | 스탯허브 — 팀별 경기 기록·통계 대시보드 (Google Sheets 연동) |

`index.html` 상단의 **🗂️ 팀관리** 버튼으로 관리앱(`manage.html`)을 열 수 있습니다.

## ⚽ 조기축구 관리앱 (manage.html)

모바일 우선 디자인의 단일 파일 앱입니다. 하단 탭으로 5개 화면을 이동합니다.

- **🏠 홈** — 등록 인원·평균 출석률·회비 잔액 요약, 다음 일정, 이번달 회비 진행률, 출석왕 TOP 5
- **👥 선수단** — 선수 추가/수정/삭제, 포지션(GK/DF/MF/FW)·등번호·연락처·가입일·활동상태 관리
- **📋 출석** — 경기/모임 일정 등록, 선수별 출석·지각·불참·사유 체크, 전체 출석/초기화, 출결 통계
- **🎯 전술** — 포메이션 프리셋(4-4-2, 4-3-3, 4-2-3-1, 3-5-2, 3-4-3, 5-3-2, 풋살 5인) 선택 후 그라운드에 선수 배치, 경기별 라인업 저장, 벤치 자동 표시
- **💰 회비** — 월 회비 설정, 월별 납부 토글(납부 시 자동 입금 기록), 입출금 내역 관리, 팀 잔액 자동 계산

여러 팀을 만들어 전환할 수 있으며(상단 우측 선택), 첫 실행 시 샘플 데이터가 채워집니다.

### 사용 방법
1. 저장소를 받아 `manage.html`을 브라우저에서 엽니다. (모바일에서는 '홈 화면에 추가' 권장)
2. 데이터는 사용 중인 브라우저에 저장됩니다. 기기/브라우저가 바뀌면 데이터는 공유되지 않습니다.
