# 여수제일병원 홈페이지 (독립본)

의료법인 한마음의료재단 **여수제일병원** 공식 홈페이지의 **단독 실행본**입니다.
이 폴더 하나만 있으면 동작하며, 다른 파일에 의존하지 않습니다.

## 사용 방법
- `index.html` 더블클릭 → 브라우저에서 바로 열림 (서버 불필요)
- 로컬 클라이언트로 옮길 때는 **이 `yeosu-jeil-hospital/` 폴더만 통째로** 복사하면 됩니다.

## 특징
- 단일 `index.html`, 외부 이미지/스크립트 의존 없음 (SVG·그래디언트만 사용)
- 디자인 시스템(CSS 변수 토큰) + 인터랙티브 효과(헤드라인 등장·스크롤 페이드업·숫자 카운트업·MRI 애니메이션)
- 완전 반응형 (데스크톱·태블릿·모바일 햄버거 메뉴)
